# ChatGPT との分担：LINE絵文字のキャラクターづくり

分担
- ChatGPT：キャラクターの見た目のデザイン（絵が得意）
- Claude（Jarvis）：その絵を図形で描き直し、動く絵文字（APNG）を規格どおりに40個まで作る（そろえることと、動かすことが得意）

Claude が図形で描き直すので、ChatGPT には**シンプルな形・太い線・少ない色**で描いてもらうのがコツです。

---

## 手順1：キャラクター案を出してもらう（ChatGPT に貼る）

```
LINEのアニメーション絵文字用に、オリジナルのマスコットキャラクターをデザインしてください。

テーマ：IT系の専門学校生の毎日（パソコン、プログラミング、資格の勉強）
使う場面：友だちとのLINEで「了解」「ありがとう」「作業中」「おめでとう」などを伝える

条件
- 既存のキャラクター、企業のマスコット、有名な作品に似せないこと
- 丸や角丸の四角など、単純な図形を組み合わせた形にすること（あとで図形で描き直すため）
- 太くて均一な輪郭線、色は輪郭線を入れて5色以内
- グラデーション、細かい模様、文字、ロゴは入れない
- 正面向き、全身、背景は白
- 小さく表示しても（約2cm角）、何のキャラかわかること

方向性が違う案を3つ、1枚の画像に横に並べて描いてください。
それぞれに、名前の案と一言の説明もつけてください。
```

## 手順2：選んだ案の設定表を作ってもらう（ChatGPT に貼る）

（手順1の中から気に入った案を1つ選んでから）

```
案○（気に入った番号）で決定です。このキャラクターの設定表を作ってください。

画像：
- 1枚の画像に、同じキャラクターの表情を8つ、4列×2行で並べる
  1. ふつう  2. 笑顔  3. 目を閉じて笑う  4. ＞＜（ごめん）
  5. 眠い（目を閉じる）  6. 照れ（ほっぺが赤い）  7. 真剣  8. 口を大きく開けて喜ぶ
- 体の形・色・線の太さは8つとも完全に同じにして、顔だけ変える
- 背景は白、文字は入れない

文章（画像とは別に、テキストで）：
- 使っている色を、すべてカラーコード（#から始まる6桁）で
- 体の形（例：横長の楕円、縦横比 10:9 など）
- 目・口・ほっぺの位置と大きさ（体の幅を100としたときの割合で）
- 手・足・アンテナなどのパーツの形と付いている位置
```

## 手順3：Claude に渡す

ChatGPT が作った次の2つを、このチャット（Claude）に送る。
1. 手順2の設定表の画像
2. 手順2の色・形の説明文（コピーして貼る）

Claude が図形で描き直し、もちびっとと同じ仕組みで、動く絵文字（8〜40個）とタブ画像を作る。

---

## 注意
- ChatGPT で作った画像を売る前に、その時点の OpenAI の利用規約で商用利用ができるか確認する。
- 既存のキャラクターに似ていないかは、人の目で確かめる（LINE の審査で落ちる一番多い理由）。
- ChatGPT が文字やロゴを描いてきたら、描き直してもらう。
