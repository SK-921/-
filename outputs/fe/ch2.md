# 第2章 アルゴリズムとデータ構造

この章では、データのしまい方（データ構造）と、探し方・並べ方（アルゴリズム）を整理します。科目Aでは「スタックとキューの動き」「探索の比較回数」「整列法の特徴」を押さえておきたいところです。科目Bの擬似言語問題の土台にもなるので、ここで動きをしっかりイメージできるようにしておきましょう。

---

## 1. 要点

### データ構造
- **スタック**：後に入れたものを先に取り出す（LIFO：Last In First Out）。入れる操作を push、取り出す操作を pop という
- **キュー**：先に入れたものを先に取り出す（FIFO：First In First Out）。入れる操作を enqueue、取り出す操作を dequeue という
- **配列**：番号（添字）で直接アクセスできる。途中への挿入・削除は後ろの要素をずらす必要がある
- **連結リスト**：各要素が「次の要素の場所（ポインタ）」を持つ。挿入・削除はポインタの付け替えだけで済むが、n番目の要素へ直接は行けない
- **木構造**：二分探索木は、どの節でも「左の部分木のすべての節 < その節 < 右の部分木のすべての節」になるように並べた木（直接の子だけを比べるのではない点に注意）

### 探索
- **線形探索**：先頭から順に調べる。データが並んでいなくても使える。見つかる場合の平均比較回数は約 n/2 回、最大 n 回
- **2分探索**：真ん中と比べて、探す範囲を半分ずつ絞る。**データが整列済みであることが前提**。最大比較回数はおよそ log₂n 回（正確には ⌊log₂n⌋ + 1 回）
- **ハッシュ法**：値から計算（ハッシュ関数）で格納場所を決める。別の値が同じ場所になる現象を「衝突（コリジョン）」、衝突を起こしたキーどうしを「シノニム」という

### 整列（並べ替え）
| 方法 | しくみ | 計算量の目安 | 安定 |
|---|---|---|---|
| バブルソート | 隣どうしを比べて入れ替える | n² | ○ |
| 選択ソート | 残りから最小を選んで先頭と交換 | n² | × |
| 挿入ソート | 整列済みの部分の正しい位置に差し込む | n² | ○ |
| クイックソート | 基準値より小さい組・大きい組に分ける | 平均 n log n（最悪 n²） | × |
| マージソート | 半分に分けて、整列しながら合体させる | n log n | ○ |
| ヒープソート | ヒープ（親が子以上の木）から最大を取り出す | n log n | × |

「安定」とは、同じ値どうしの元の順番が、整列後も保たれることです。

## 2. 覚え方

### スタックは「積み重ねたお皿」、キューは「レジの行列」
お皿は上に積んで、上から取ります。下のお皿を先に取ることはできません。これがスタックです。
レジの行列は、先に並んだ人から会計します。割り込みはできません。これがキューです。
問題を解くときは、スタックは**縦の箱**、キューは**横の筒**を紙に描いて、数字を書いたり消したりしながら追うと、取り違えを防げます。

### 2分探索の回数は「2を何回掛けたら超えるか」
データが n 個のとき、「2, 4, 8, 16 …」と倍にしていき、**初めて n を超えたときの掛けた回数**が最大比較回数です。
- 100個 → 2⁷ = 128 で初めて超える → 最大7回
- 1,000個 → 2¹⁰ = 1,024 で初めて超える → 最大10回

「1,000個でも10回で見つかる」と覚えておくと、線形探索（最大1,000回）との差が実感できます。

### 整列法は「遅い3兄弟」と「速い3兄弟」
- 遅い3兄弟（n²）：**バブル・選択・挿入**（基本的で、しくみが単純）
- 速い3兄弟（n log n）：**クイック・マージ・ヒープ**

安定かどうかは「**バ・挿・マ は安定**（バブル・挿入・マージ）」と覚え、それ以外は安定ではない、とまとめてしまいましょう。

### クイックソートは「名前は速いが、運が悪いと遅い」
基準値（ピボット）の選び方が悪いと、毎回片側に1個しか入らない偏った分割になり、n² になります（例：整列済みのデータで先頭をピボットに選んだとき）。「平均は速い、最悪は遅い」がセットです。

## 3. 間違えやすいポイント

- **LIFO と FIFO の取り違え**：「スタック＝後入れ先出し」。英語の頭文字で覚えるより、お皿と行列のイメージで思い出す方が混乱しにくいです
- **2分探索の前提を忘れる**：「並んでいないデータに2分探索は使えない」という点は、選択肢のひっかけになりやすいところです
- **平均と最大の混同**：線形探索の「平均 n/2 回」と「最大 n 回」、どちらを聞かれているか問題文をよく読みましょう
- **選択ソートと挿入ソートの混同**：選択は「残りから**選んで**持ってくる」、挿入は「手元のカードを正しい位置に**差し込む**」。トランプを手で並べる動きが挿入ソートです
- **クイックソートの最悪計算量**：「クイックソートは常に n log n」は誤りです
- **配列と連結リストの得意・不得意**：「n番目にすぐアクセス」は配列が得意、「途中に挿入・削除」は連結リストが得意。逆に覚えないよう注意しましょう

## 4. 例題（自作）

**問題**　空のスタックに対して、次の操作を左から順に行った。pop で取り出された値を、取り出された順に並べたものはどれか。

push(4)、push(9)、pop、push(1)、push(6)、pop、push(8)、pop、pop

ア　4, 9, 1, 6　　イ　9, 6, 8, 1　　ウ　9, 6, 8, 4　　エ　9, 8, 6, 1

### 解説

スタックの中身を、左を底・右を一番上として書きながら追います。

| 操作 | スタックの中身（左が底） | 取り出された値 |
|---|---|---|
| push(4) | 4 | |
| push(9) | 4, 9 | |
| pop | 4 | **9** |
| push(1) | 4, 1 | |
| push(6) | 4, 1, 6 | |
| pop | 4, 1 | **6** |
| push(8) | 4, 1, 8 | |
| pop | 4, 1 | **8** |
| pop | 4 | **1** |

取り出された順は **9, 6, 8, 1**、正解は **イ** です。最後にスタックの底には 4 が残ります。

**選択肢のわな**
- ア（4, 9, 1, 6）：キューだと思って「先に入れたものから」取り出したときの答え
- ウ（9, 6, 8, 4）：最後の pop で、一番上の 1 ではなく底の 4 を取ってしまったときの答え
- エ（9, 8, 6, 1）：中身を書かずに頭の中だけで追い、6 と 8 の取り出し順を取り違えたときの答え

**比べてみよう：同じ操作をキューで行うと？**
push を enqueue、pop を dequeue に読み替えると、取り出される順は 4, 9, 1, 6 になり、最後に 8 が残ります。同じ操作でも結果がまったく違うことを、表を描いて確かめてみてください。
