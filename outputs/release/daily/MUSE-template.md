# Muse への依頼：今日の無料記事を note に公開する（日付：YYYY-MM-DD）

## 守ってほしいこと
1. **公開ボタンを押す前に、必ず持ち主に確認を取る。** プレビューのスクリーンショットを送り、OK をもらってから押す。
2. 本文は書き換えない。気になる点は直さずに報告する。
3. この記事は**無料**。有料設定にしない。
4. 迷ったら、下書きのまま止めて報告する。
5. ここに書いていない操作（削除、ほかの記事の編集、設定の変更、お金の支払いなど）はしない。

## 手順
1. note で「投稿」→「テキスト」を開く。
2. `post.txt` の1行目をタイトルに、3行目から最後までを本文に貼る。
3. 本文の最後にある「もっと詳しく：（記事タイトル）」の行の下に、持ち主の note にあるそのタイトルの記事を「記事の埋め込み」で入れる。見つからなければ、その行ごと消す。
4. ハッシュタグ：#基本情報技術者試験 #AI活用 #ClaudeCode #専門学生 #資格勉強 から、内容に合うものを3つまで。
5. **ここで止めて**、持ち主にプレビューを送って確認を取る。
6. OK が出たら「投稿する」を押し、記事のURLを持ち主に送る。
