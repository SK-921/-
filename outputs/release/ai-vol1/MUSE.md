# Muse への依頼：AI活用シリーズ 第1弾を note で公開する

このフォルダの中身は、Claude（Jarvis）が作り、チェック担当の確認を通した完成品です。
あなた（Muse）の仕事は、これを note に載せることだけです。

## 守ってほしいこと

1. **公開ボタンを押す前に、必ず持ち主に確認を取る。** プレビューのスクリーンショットを送り、「OK」の返事をもらってから押す。
2. 本文の中身は書き換えない。誤字などに気づいたら、直さずに持ち主へ報告する。
3. 価格は 500円 から変えない。
4. 途中で失敗したり迷ったりしたら、下書きのまま止めて持ち主に報告する。
5. ここに書いていない操作（記事の削除、ほかの記事の編集、設定の変更、お金の支払いなど）はしない。

## 手順：note に公開する

1. note にログインし、「投稿」→「テキスト」を開く。
2. タイトルに `01-title.txt` の内容を入れる。
3. 見出し画像に `images/00-cover.png` を設定する。
4. 本文に `03-free.txt` を貼る（無料で読める部分）。
5. 続けて、その下に `04-paid.txt` を貼る（有料部分）。
6. **コードの部分**：本文の中に「▽ ここから」で始まる行と「△ ここまで」の行が19か所ある。そのあいだの行（ファイルの中身・コマンド・ログ）は、行の頭の「＋」→「コード」で作ったコードブロックの中に入れる。▽ と △ の行はコードブロックの外に残す。
7. （できれば）「1. 全体の仕組み：…」〜「8. おわりに」の8行を大見出しに、「◆」で始まる行を小見出しにする。
8. この記事には、本文に差し込む画像はない（見出し画像だけ）。
9. 「公開に進む」を押し、`02-settings.txt` のとおり設定する。
   - ハッシュタグ
   - 販売設定：有料、500円
   - 有料エリアの開始位置：「1. 全体の仕組み」の直前
10. **ここで止める。** 持ち主に、次のプレビューを送って確認を取る。
    - 無料部分の終わりと、有料ラインの位置がわかる画面
    - コードブロックが1つ以上（崩れていないか見るため）
11. OK が出たら「投稿する」を押す。公開された記事のURLを持ち主に送る。

## 終わったら

持ち主に note の記事URLを送る。
