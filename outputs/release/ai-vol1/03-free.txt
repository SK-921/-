はじめに

専門学校で学んでいる学生です。
Claude Code を使って、自分専用のAI秘書を作りました。名前は「Jarvis（ジャービス）」です。
SNS で紹介されていた「AI秘書の作り方」のまとめを出発点にしつつ、自分の毎日に合わせて、ルールやファイルを組み立てました。

この記事では、作った手順と、実際に動かしてみてつまずいたところを、実物の設定ファイルといっしょにまとめます。うまくいった話だけでなく、失敗したところもそのまま書きます。


この記事でわかること

・Claude Code で「自分専用のAI秘書」を作るときの、全体の仕組み（4つの部品）
・筆者が実際に使っている（または最初に使っていた）設定ファイルとスクリプトをもとにした、コピーして使える形のファイル
・AIにファイルの削除や外部への送信をさせないための、権限の絞り方と、その理由
・作る担当とチェック担当を分けると何が良いか（実際に見つかったミスの例つき）
・最初の自動実行で同時に起きた2つの問題（仕事が進まなかった／ボードを更新できなかった）の原因と、その直し方
・cron を使った定期実行の設定例
・料金・使える量の枠・規約まわりで気をつけること


対象読者

・Claude Code を少し触ったことがある学生・初心者
・「AI秘書」を自分でも作ってみたいけれど、何から作ればいいか分からない人
・AIに作業を任せたいけれど、勝手にファイルを消されたり、外に送られたりするのが心配な人

※ Claude Code のインストールや基本の使い方は、この記事では短くしか書きません。くわしくは公式の説明を見てください。
※ この記事は「お金をかせぐ方法」の記事ではありません。AI秘書の作り方と、動かした記録の記事です。


作った結果（事実だけ書きます）

・2026年11月14日：Jarvis の土台（判断軸・仕事ボード・作る担当とチェック担当・定期実行のスクリプト）を作った
・同じ日に、自動実行を1回だけ試した。このときは、どの仕事も進まなかった。原因は、ボードに入っていた例のタスクの締切が「金曜」のような曜日だけで、テーマや字数などの要件も書かれていなかったこと
・同じ1回の実行で、ボードを更新することもできなかった。原因は、フォルダを「信頼済み」にしていなかったため、settings.json の許可（allow）が無視されたこと
・2026年11月18日：Jarvis に、基本情報技術者試験（FE）科目Aの要点まとめを作らせた。1日で、全7章と、本文の図7枚・見出し画像1枚ができた
・その途中で、チェック担当が、用語の定義の取り違えや「言い過ぎ」の表現を見つけ、直すことができた
・ただし、筆者自身が読み直して書き直す作業は、まだ残っている
・定期実行（cron）は、動くように作ってあるが、執筆時点では、まだ cron に登録して動かした記録はない
・売上：執筆時点（2026年11月18日）では、まだ0円です。この要点まとめは、まだ販売前です


見本：Jarvis に「任せないこと」

有料部分ではファイルの中身をまるごと載せていますが、ここでは判断軸（CLAUDE.md）の一部を、見本として紹介します。Jarvis には、次のことを任せていません。

・お金が動くこと（購入・支払い・課金）
・外部への送信（メール・投稿・メッセージ）。ただし、GitHub への git push だけは筆者が許可している
・ファイルの削除
・note などへの公開・価格設定・SNS への投稿（Jarvis 自身はやらない。公開は別のAIエージェントが、筆者の OK をもらってから行う）
・学校の課題の問題・答えや、教科書・過去問のコピーを成果物に入れること

有料部分では、これをルールとして書くだけでなく、設定ファイルで「仕組みとして」止める方法も書いています。
