# Muse への依頼：FE要点まとめ 第1弾を note で公開し、Instagram で知らせる

このフォルダの中身は、Claude（Jarvis）が作って確認を済ませた完成品です。
あなた（Muse）の仕事は、これを note と Instagram に載せることだけです。

## 守ってほしいこと

1. **公開ボタン・投稿ボタンを押す前に、必ず持ち主に確認を取る。** プレビューのスクリーンショットを送り、「OK」の返事をもらってから押す。
2. 本文の中身は書き換えない。誤字などに気づいたら、直さずに持ち主へ報告する。
3. 価格は 500円 から変えない。
4. 途中で失敗したり迷ったりしたら、下書きのまま止めて持ち主に報告する。
5. ここに書いていない操作（記事の削除、ほかの記事の編集、設定の変更、お金の支払いなど）はしない。

## 手順A：note に公開する

1. note にログインし、「投稿」→「テキスト」を開く。
2. タイトルに `01-title.txt` の内容を入れる。
3. 見出し画像に `images/00-cover.png` を設定する。
4. 本文に `03-free.txt` を貼る（無料で読める部分）。
5. 続けて、その下に `04-paid.txt` を貼る（有料部分）。
6. 本文中に「【画像】ここに ○○.png を入れる（入れたらこの行は消す）」という行が7か所ある。それぞれ、その行を消して、同じ位置に `images/○○.png` を挿入する。
7. （できれば）見出しを整える。
   - 大見出し：「第1章 基礎理論」〜「第7章 計算問題まとめ：見積り・稼働率・損益計算」の7行と「おわりに」
   - 小見出し：各章の「1. 要点」「2. 覚え方」「3. 間違えやすいポイント」「4. 例題（自作）」
8. 「公開に進む」を押し、`02-settings.txt` のとおり設定する。
   - ハッシュタグ
   - 販売設定：有料、500円
   - 有料エリアの開始位置：「第1章 基礎理論」の直前
9. **ここで止める。** 持ち主に、プレビュー（無料部分の終わりと有料ラインの位置がわかる画面）を送って確認を取る。
10. OK が出たら「投稿する」を押す。公開された記事のURLを持ち主に送る。

## 手順B：Instagram で知らせる（手順Aで公開URLが出てから）

1. 画像は `instagram/08-instagram.png`、投稿文は `instagram/caption.txt` を使う。
2. **投稿する前に**、画像と投稿文を持ち主に見せて確認を取る。
3. OK が出たら投稿し、投稿のURLを持ち主に送る。
4. プロフィールのリンクを note の記事URLに変えるかどうかは、持ち主に聞いてから行う。

## 終わったら

持ち主に次の2つを送る。
- note の記事URL
- Instagram の投稿URL
