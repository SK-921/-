この記事でわかること

・基本情報技術者試験（FE）科目Aの7分野について、押さえておきたい要点の整理
・用語や計算手順を思い出しやすくするための覚え方
・選択肢のひっかけになりやすい「間違えやすいポイント」
・各章1問ずつの自作例題と、正解だけでなく誤答の選択肢がなぜ誤りかの解説


対象読者

・これから FE を受験する人、特に科目Aの対策を始めたばかりの人
・参考書を一通り読んだが、要点を短く見直せる資料がほしい人
・基数変換・稼働率・損益分岐点などの計算問題で手が止まりやすい人

※ この記事は要点の整理と覚え方をまとめたもので、参考書や過去問演習の代わりになるものではありません。参考書・公式の情報とあわせて使ってください。


目次（全7章）

第1章 基礎理論：2進数・基数変換・論理演算
第2章 アルゴリズムとデータ構造：スタック・キュー・探索・整列
第3章 コンピュータ構成：CPU・メモリ・キャッシュ
第4章 ネットワーク：OSI基本参照モデル・TCP/IP・IPアドレス
第5章 セキュリティ：暗号・認証・攻撃手法
第6章 データベース：正規化・SQL・トランザクション
第7章 計算問題まとめ：見積り・稼働率・損益計算

各章は「1. 要点 → 2. 覚え方 → 3. 間違えやすいポイント → 4. 自作の例題1問と解説」の順で構成しています。

基本情報技術者試験の勉強をしている専門学校生です。科目Aの要点を、自分で作ったAI秘書と一緒に7分野にまとめました。


AIの利用について

この記事は、筆者が Claude Code で作ったAI秘書が下書きし、同じ Claude Code の中のチェック担当（サブエージェント）が事実確認をしたものです。


有料部分について

ここから先の有料部分では、上の目次の全7章を収録しています。
各章の例題は、過去問の文章や数値を写さずに新しく作ったものです。誤答の選択肢についても「どんな勘違いをするとその答えになるか」を解説しているので、自分のミスの傾向を確かめる材料として使ってもらえたらうれしいです。
