# note で何が売れているか（2026-11-18 調べ）

note.com を直接スクレイピングするのはやめた（規約上のリスクがあるため）。note 社が公式に出した分析と、それを報じた記事から調べた。

## わかったこと

- note 社は 2026年1月7日に、約30万件の有料記事とメンバーシップのデータを分析した結果を発表した
  - 伸びているジャンル：収入アップ・仕事系の「AI活用」「SNS運用」「複業・在宅ワーク」、課題解決系の「育児・教育」
  - 売れているのは、有名人や専門家でなくても「自分の体験を整理して、同じ立場の人に向けて書いた」記事
  - 文字数と売上の相関はほぼゼロ。効くのはジャンルの選び方と、無料部分で価値を見せること
  - 各分類の売上上位20%で比べると、実用ノウハウ系の平均価格は1,842円で、読み物系の約1.9倍
  - メンバーシップ（月額）の売上は前年比80%超の増加。有料記事は26.8%増
- 単発の有料記事は 500〜3,000円 の価格帯に集中している（解説記事による）

## まだわからないこと

- ジャンル別の順位（元の発表では図になっていて、文字で取れなかった）→ 本人が PR TIMES の元発表の図を見て確かめる

## ここから決めたこと

1. **ジャンル**：「AI活用」を中心にする。いま Claude Code で AI秘書を作り、Muse と組み合わせて公開まで動かしている。これはそのまま「自分の体験」になり、同じ立場の学生に向けて書ける
2. **FE要点まとめ**：「育児・教育」に近い学習系として、第1弾をそのまま売る。続編を出すかは売れ行きで決める
3. **書かないもの**：「稼ぎ方」「副業で月○万円」系。実績がないうちに書くと、うそか誇大広告になる。実際に売上が出たら「1か月の記録」として事実だけ書く
4. **ペース**：有料記事を毎日出すと質が落ち、スパム扱いされる危険もある。そこで、無料の短い記事を毎日出し（読者を集める）、有料記事は週1本にする。読者が増えたらメンバーシップを考える
