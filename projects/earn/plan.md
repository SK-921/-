# 稼ぐプロジェクト：FE要点まとめ（note）

## 方針
- 商品：基本情報技術者試験（FE）の要点まとめ。自分の言葉で書いた要点・覚え方・間違えやすいポイント
- 売り場：note の有料記事 ¥500
- 買う人：HAL の同級生、FE 受験者
- 取り分の目安：1冊 約¥428（決済手数料とプラットフォーム利用料を引いた額。出品前に note の最新の手数料を確認する）
- 目標：月8冊（約¥3,400）で Claude Pro の月額（$22）分をまかなう

## 線引き（絶対に守る）
- 売らないもの：学校の課題の問題や答えそのもの、教科書・参考書・過去問のコピーや丸写し、図表の転載
- 過去問は「どの分野がよく出るか」の分析と、自分で作った例題で代わりにする
- 受託の仕事（他人から頼まれて作る仕事）は、就職先の副業ルールを確認するまで対象外
- Jarvis は公開・投稿をしない。公開と投稿は Muse が本人の OK をもらってから行う。価格の変更や販売の取り消しは本人だけが行う
- AI の手を借りて作った場合は、note の規約とガイドラインに沿って表記する

## 自動化の範囲
| 作業 | 担当 |
|---|---|
| 章ごとの下書き | Jarvis（maker）が自動 |
| 事実チェック | Jarvis（checker）が自動 |
| 宣伝文の案3つ | Jarvis が自動 |
| 売上の集計 | Jarvis が自動（売上の CSV は本人が `sales.csv` に貼る） |
| 公開キットづくり（原稿の分割・画像・投稿文・Muse への指示書） | Jarvis が自動（`outputs/release/<名前>/`） |
| note への貼り付け・公開、Instagram への投稿 | Muse（公開・投稿の前に本人の OK をもらう） |
| 最終確認（OK を出す） | **本人** |

## 構成（第1弾：科目Aの頻出分野）
1. 基礎理論：2進数・基数変換・論理演算
2. アルゴリズムとデータ構造：スタック・キュー・探索・整列
3. コンピュータ構成：CPU・メモリ・キャッシュ
4. ネットワーク：OSI参照モデル・TCP/IP・IPアドレス
5. セキュリティ：暗号・認証・攻撃手法
6. データベース：正規化・SQL・トランザクション
7. マネジメント・ストラテジ：見積り・稼働率・損益計算

各章の形：要点（箇条書き）→ 覚え方 → 間違えやすいポイント → 自作の例題1問と解説

## 7日間プラン
| 日 | やること | 担当 |
|---|---|---|
| 1日目 | 第1〜2章の下書き → チェック | Jarvis |
| 2日目 | 第3〜4章の下書き → チェック | Jarvis |
| 3日目 | 第5〜6章の下書き → チェック | Jarvis |
| 4日目 | 第7章の下書き → チェック、全体の目次と無料部分を作る | Jarvis |
| 5日目 | 全体を読んで直す（自分の言葉・自分の覚え方に書き換える） | 本人 |
| 6日目 | 宣伝文3案を作る → 本人が選ぶ | Jarvis → 本人 |
| 7日目 | note に公開、宣伝を投稿 | **本人** |

公開したあとは、毎週月曜に売上を集計し、次の1冊（第2弾：科目B のアルゴリズム問題の読み方 など）を決める。
